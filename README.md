# Angeline Lee Pei Shih - Portfolio Website

A modern, responsive portfolio website showcasing Angeline Lee's academic achievements, awards, and leadership experience.

## Features

- **Modern Design**: Clean, gradient-based design with smooth animations
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth scrolling, hover effects, and scroll animations
- **Performance Optimized**: Fast loading with optimized CSS and JavaScript
- **Accessibility**: Semantic HTML structure with proper ARIA labels

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About**: Personal introduction and language skills
3. **Education**: Academic background (Negeri Sembilan Matriculation College)
4. **Awards & Recognition**: Showcase of competitions and achievements including:
   - PIITRAM 2024 Gold Medal
   - Arc: Robosurvivor 2026 Finalist
   - UMHackathon 2025 Participant
   - Intervarsity Youth Startup Competition Champion
   - And more...
5. **Leadership**: Leadership roles and event organizing experience
6. **Contact**: Contact information and contact form

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with:
  - Flexbox and Grid layouts
  - CSS animations and transitions
  - Gradient backgrounds
  - Responsive design with media queries
- **JavaScript**: Interactive functionality including:
  - Mobile navigation
  - Smooth scrolling
  - Scroll progress indicator
  - Form validation
  - Intersection Observer animations
- **Font Awesome**: Icons for visual enhancement
- **Google Fonts**: Inter font family for modern typography

## How to Use

1. **Local Development**:
   - Open `index.html` in your web browser
   - No server required for local viewing

2. **Web Deployment**:
   - Upload all files to your web server
   - Ensure all files are in the same directory
   - Access via your domain/hosting URL

3. **Customization**:
   - Edit `style.css` to modify colors, fonts, or layout
   - Update `index.html` to change content
   - Modify `script.js` for additional functionality
